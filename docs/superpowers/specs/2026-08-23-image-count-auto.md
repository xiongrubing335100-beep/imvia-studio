# 图片生成数量 Auto 设计

## 目标

图片生成增加默认的 `Auto` 数量模式。Auto 不把生成数量限制为 1、2 或 4，也不在本地解析或改写提示词；Lovart 根据原始提示词决定产出数量，工作台完整接收并展示实际返回的所有图片。该行为必须支持图片拆分等一次返回多张结果的任务。

## 交互

- 图片生成的“生成数量”选项为 `Auto`、`1个`、`2个`、`4个`，默认 `Auto`。
- 视频生成保持现有固定数量交互。
- Auto 任务在会话桥消息中显示 `Auto`，不能回退或误报为 `1个`。

## 数据契约

- Auto：`settings.count_mode = "auto"` 且 `settings.count = null`。
- 手动：`settings.count_mode = "fixed"` 且 `settings.count` 为正整数。
- 兼容旧快照：缺少 `count_mode` 且 `count` 为正整数时视为 fixed。
- Auto 执行时不向 Lovart 添加固定数量参数，也不向原始提示词追加数量要求。

## 结果契约

- 结果数量以 Lovart 实际返回的 artifacts 为准。
- 不比较实际数量与 UI 请求数量，不截断、不补齐，也不把多个结果合成一张。
- 现有单张与多张结果布局继续依据 `artifacts.length` 渲染。

## 非目标

- 不实现本地自然语言数量识别。
- 不为 Lovart API 虚构目前不存在的 count 参数。
- 不改变视频生成数量行为。
- 不提交、推送或发布仓库变更。
