# IMVIA Studio 多提供商外部 API 连接中心设计

## 状态

设计已在对话中分节确认。本文只记录设计，不包含实现代码，也不提交仓库。

## 目标

为 IMVIA Studio 增加一个可扩展的多提供商 API 连接中心。用户可以保存多个外部图片和视频生成服务、多个账户连接和多个模型；工作台把每个任务统一发送到当前 Codex 会话，由 Codex 通过连接器调用选定的外部服务，并持续回传状态和结果。

Lovart 是其中一个独立提供商，继续遵守现有的 IMVIA 会话桥、凭据隔离和显式激活规则。

## 范围

第一阶段覆盖图片和视频生成 API，包括文生图、图生图、文生视频和图生视频。标准 REST API 通过配置接入；签名鉴权、特殊上传或其他复杂协议通过专用适配器接入。

文本、语音、文件处理等非生成 API 不纳入第一阶段，但连接器接口必须保留能力扩展点。

## 核心架构

```text
工作台
  -> 不可变任务快照
  -> 当前 Codex 会话桥
  -> 统一任务路由器
  -> 提供商注册中心
       -> 通用 REST 适配器
       -> 专用提供商适配器
  -> 外部 API
  -> 状态归一化与结果导入
  -> Codex / 工作台
```

浏览器不直接调用外部 API。工作台只提交不含密钥的任务快照；服务端在 Codex 执行任务时从本机凭据库解析密钥。

## 系统组件

### 提供商注册中心

维护提供商、连接器类型、支持能力、模型和适配器版本。Lovart 作为内置提供商注册。新增标准 REST 提供商不需要重新发布工作台；复杂提供商需要安装受信任的专用适配器。

### 连接配置库

保存非敏感配置：

- `connection_id`、显示名称、提供商名称和启用状态
- 连接器类型：`generic_rest` 或 `adapter`
- 能力列表和模型列表
- API 基础地址
- 上传、创建任务、查询状态、取消任务、获取结果的接口映射
- 轮询间隔、超时、并发限制和配置版本
- `credential_ref`，仅为本机凭据引用

配置修改递增版本号。已经创建的任务保留原配置版本，避免执行过程中静默改变路由。

### 安全凭据库

每个提供商和账户连接独立保存密钥。密钥通过本机安全窗口写入随 IMVIA 提供的私有凭据助手存储，不使用 macOS 钥匙串，也不读取现有 Lovart 插件的凭据。密钥不进入浏览器状态、HTTP 参数、任务快照、Codex 消息、日志或错误文本。

支持更换密钥、停用连接和删除连接。删除连接只删除 IMVIA 自己管理的凭据项，不读取或修改现有 Lovart 插件的凭据。

### 通用 REST 适配器

通过声明式配置支持：

- Bearer Token、API Key Header、Basic Auth 和 OAuth2 Client Credentials
- JSON 与 Multipart 文件上传
- 同步返回结果或异步返回任务 ID
- 任务 ID、状态、进度、错误、费用和结果地址的字段映射
- 状态查询的轮询间隔、退避和超时
- 单结果或结果数组

默认只允许 HTTPS；访问本机或局域网地址必须显式开启本地连接选项。

### 专用适配器接口

专用适配器用于 HMAC/自定义签名、特殊文件上传、Webhook 或非标准状态协议。适配器提供统一的能力声明、提交、轮询、取消和结果导入接口。适配器必须来自受信任的本地安装，网页配置不能注入任意可执行代码。

## 任务数据契约

任务快照包含：

- `job_id`
- `provider_id`
- `connection_id`
- `connection_config_revision`
- `model_id` 或当前提供商内的 `auto`
- 原始提示词、素材引用和生成参数
- 幂等键
- `activation = workbench_action`

任务快照不包含任何明文凭据。提供商选择是任务级的；不支持跨提供商自动切换。`Auto` 只表示当前提供商内部的模型或数量自适应，不表示自动选择另一家 API。

## 执行生命周期

统一状态为：

```text
created
-> sent_to_codex
-> validated
-> uploading
-> submitted
-> generating
-> succeeded | failed | cancelled
```

外部服务有费用信息时，允许进入 `awaiting_cost_confirmation`。费用未知时显示“提供商计费信息未知”，默认仍要求用户确认，不自动扣费或确认。

每个任务使用唯一幂等键。网络错误只重试安全的查询和轮询；提交操作只有在连接器明确支持幂等时才允许重试。任务可以排队，但当前 Codex 会话按其会话桥能力有序处理，不把排队任务伪装成并行执行。

首版以轮询为主。Webhook 作为后续专用适配器能力，不要求用户暴露公网端口。

## 状态、错误和结果

### 错误分类

- 鉴权失败：提示更换密钥。
- 参数或模型不支持：指出具体字段或能力。
- 网络、代理或超时：允许安全重试并保留任务编号。
- 提供商限流：显示提供商返回的等待时间。
- 结果解析失败：保留脱敏后的原始响应摘要。
- 用户取消：停止本地轮询；提供商支持取消时调用取消接口。

不允许静默更换提供商、账户或模型。Lovart 失败仍显示为 Lovart 失败。

### 结果契约

结果统一为 artifacts 数组，支持图片、视频、URL、Base64、文件流和多结果返回。工作台按实际返回数量展示，不截断、不补齐、不强制合并。所有结果均可下载、放大或播放，并可加入素材库。

## 工作台交互

在现有模型选择上方增加“提供商”选择：

- 选择提供商后，模型列表按其能力过滤。
- 选择已保存的连接账户。
- 没有连接时显示“添加 API 连接”。
- Lovart 继续作为默认内置提供商。
- 不提供跨提供商的 `Auto`。

新增“设置 → API 连接”页面，提供添加、编辑、测试、停用、更换密钥、删除和复制模板。连接测试只能进行只读探测，不创建生成任务。导入导出模板不包含密钥。

工作台顶部只展示整体连接状态；任务卡展示实际提供商、模型和当前阶段。生成中显示“提供商生成中…”，完成后回到统一结果展示。

## API 连接配置流程

1. 用户打开“添加 API 连接”。
2. 选择通用 REST 或专用适配器。
3. 填写服务地址、鉴权方式、能力和模型。
4. 配置上传、提交、状态和结果字段映射。
5. 通过本机安全窗口填写密钥。
6. 执行只读连接测试。
7. 保存连接并生成配置版本。

连接测试不得上传素材、创建项目、提交生成、确认费用或读取结果。

## 安全与隔离

- 浏览器永远不直接访问外部服务。
- 凭据只在 IMVIA 私有凭据助手中解析，并按连接隔离。
- 凭据引用不能替代明文密钥进入任务数据。
- 日志和错误必须脱敏。
- 默认 HTTPS；私有地址需要显式开关。
- 专用适配器必须受信任安装。
- IMVIA/Lovart 与现有 Lovart 插件保持提供商隔离。

## 测试要求

- 通用 REST 适配器契约测试。
- 每个专用适配器的提交、轮询、取消、失败和结果测试。
- 多连接、配置版本和幂等测试。
- 会话桥消息接收、状态同步和结果导入端到端测试。
- 重试不会重复提交或重复扣费的测试。
- 密钥不出现在浏览器、快照、日志和错误文本中的安全测试。
- 多图片、多视频和异步结果数组展示测试。

## 非目标

- 第一阶段不接入文本、语音和文件处理等非图片/视频生成 API。
- 不做跨提供商自动故障转移。
- 不允许网页直接执行用户提供的任意代码。
- 不通过本地解析提示词来猜测外部 API 的生成数量。
- 不改变现有 Lovart 插件的凭据或工作流。
- 不在本设计阶段修改代码、发布构建或提交仓库。

## 验收标准

完成后，用户应能在同一工作台中保存至少两个不同提供商和多个账户连接，分别选择其图片或视频模型，提交任务到当前 Codex 会话，并看到从提交到结果的连续状态；任一提供商失败时都能看到明确原因，且任务不会被静默转移到其他提供商，密钥也不会出现在浏览器或任务消息中。
